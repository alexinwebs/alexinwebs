### 🚀 Featured Project

**[MailPilot AI](https://github.com/alexinwebs/mailpilot-ai)** — a self-hosted, open-source AI email assistant for Gmail.  
Reads your inbox, drafts AI-generated replies, and **only sends after human approval** — the AI can classify, draft, and critique, but a deterministic policy engine (not the model) decides what actually gets sent. Built with React, Fastify, Prisma, PostgreSQL, Redis, and real Gmail Pub/Sub push notifications. Deployed live on Render.
